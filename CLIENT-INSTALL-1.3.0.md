# SHOP-MOD-lyn 1.3.0 installation

Server: Fabric Loader 0.20.1+, Fabric API for Minecraft 26.2, ECO-API-lyn 1.2.0+, and SHOP-MOD-lyn 1.3.0. Use Java 25+.

Players: Fabric Loader, Fabric API for Minecraft 26.2, and SHOP-MOD-lyn 1.3.0. ECO is required only on the server. Install other item mods on the sides required by those mods to trade their items.

Stop the server and replace the previous SHOP JAR. Every client must also update SHOP to 1.3.0. Keep existing price files and world data. The server generates config/shop-mod-lyn/auctions.json on first start.

Use /shop and /sell for the configured server shop; use /ah for the player market and timed auctions. PROFILE and ECO do not need source changes for this update.
